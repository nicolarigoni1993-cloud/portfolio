# Ninth Slate — Lead Scoring

Use this to decide which opportunities deserve time.

Score each 0–2.

## Scope clarity
0 unclear
1 partly clear
2 clearly defined

## Stack fit
0 outside current capability
1 learnable with moderate risk
2 strong fit

## Access / reproducibility
0 no access / impossible to verify
1 partial
2 repo/test environment/repro available

## Budget realism
0 clearly unrealistic
1 uncertain
2 reasonable for scope

## Client communication
0 vague/problematic
1 average
2 clear and responsive

## Portfolio value
0 low
1 useful
2 strong case study/review potential

## Risk
0 high risk
1 manageable
2 low risk

### Interpretation
12–14: prioritize
9–11: good candidate
6–8: inspect carefully
0–5: usually decline

## Red flags
- asks for free full solution before contract
- wants account credentials in chat
- unclear ownership/authorization
- requests unauthorized security testing
- impossible deadline
- "simple job" with huge scope
- refuses milestone clarity
- asks to work outside platform rules where prohibited
